# 单据模板字段取值规则汇总

本文档按字段名称汇总 14 个单据模板的取值来源，用于快速对比同一字段在不同单据中的来源差异。

## 说明

| 说明项 | 内容 |
| --- | --- |
| 统计口径 | 只统计 14 个单据模板；RO DATA BASE & PO record template.xlsx 是数据源文件, 不作为单据模板。 |
| 忽略文件 | 忽略 .~ 开头的 Excel 临时锁文件。 |
| 核对依据 | 结合模板单元格中的中文来源注释、公式和 模板取数逻辑说明.md；固定值以当前模板实际内容为准。 |
| 价格选择规则 | DATA BASE 的价格列通常按 Category 选择: 1=combo, 2=rod, 3=reel。G/H/I=GS-SK/YM FOB, J/K/L=EMAX-GS PTE FOB, M/N/O=EMAX PTE FOB。例外: YM 主体固定取 G列 GS-SK/YM COMBO FOB 2026。 |
| 数量选择规则 | PI/PO 使用客户PO N列 Order Quantity；CI/PL 使用 PO record AM列 SHIP QTY。 |
| SK/YM 主体过滤规则 | SK/YM 层按 PO record 的 CATEGORY 判断主体：1/2 属于 YM，3 属于 SK。工作台或 CLI 已明确选择 seller=SK/YM 时，只预览和导出该主体对应行，不自动把另一主体拆成额外文件。GS PTE 与 EMAX PTE 不使用此规则。 |
| 空白含义 | 矩阵表中空白表示该单据没有对应字段, 或模板未出现该字段。 |
| 生成日期 | 2026-06-18 |

## 关键规则摘要

- 价格列通常按 `DATA BASE` 的 `Category` 选择：`1=combo`、`2=rod`、`3=reel`；YM 主体例外，固定取 `DATA BASE` G列 `GS-SK/YM COMBO FOB 2026`。
- SK/YM 层的预览与导出按已选主体过滤 `PO record.CATEGORY`：`1/2 -> YM`，`3 -> SK`。页面选择 SK 或 YM 后，只处理该主体对应行。
- `G/H/I` 对应 `GS-SK/YM FOB`；`J/K/L` 对应 `EMAX-GS PTE FOB`；`M/N/O` 对应 `EMAX PTE FOB`。
- `PI/PO` 数量通常取 `客户PO N列 Order Quantity`；`CI/PL` 数量通常取 `PO record AM列 SHIP QTY`。
- `RO DATA BASE & PO record template.xlsx` 是数据源文件，不计入单据模板。
